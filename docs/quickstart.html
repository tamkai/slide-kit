Slide Kit

スライドは、二段階で作る

Claude Code / Codex でスライドを作るためのキットです。 入れ方と、使い方の考え方を1ページにまとめました。

いちばん大事なこと

このキットは、スライドを「構成をつくる」と「スライドにする」の二段階に分けます。 面倒に見えますが、これが速さの理由です。

「スライド作って」と一息で頼むと、AIは話の順番と見た目を同時に決めてしまいます。 すると、直したいのが順番だけでも、毎回デッキ全体が作り直しになります。

先に構成だけを作って人が読む。 そこを直してからスライドにする。それだけで、やり直しが劇的に減ります。

1

構成をつくる

この原稿からスライド構成を作って

何枚にするか、各枚で何を言うかの一覧が出てきます。まだ絵は出ません。 ここで止まるので、遠慮なく直してください。 「3枚目と4枚目を入れ替えて」「この山は2枚に割って」で通ります。

2

スライドにする

これをスライドにして

2種類のどちらで作るか聞かれます（次の項目）。 最後にスピーカーノート入りの PowerPoint が出てきます。

2種類から選ぶ

聞かれたら、あとで文字を直す可能性があるかどうかだけで決めてください。 迷ったら B が安全です。

A. 画像スライドB. 編集できるスライド
見た目 AIイラストで世界観が強い 崩れない・端正
あとで文字を直す できない できる
途中の確認 できた画像を見る ブラウザで見る
向いている場面 内容が固まった講演・発表 回覧して直しが入る資料
A を選ぶときの注意

画像スライドは、文字が絵に焼き込まれます。 PowerPointを開いても文字は直せません。誤字が見つかったら作り直しです。

また画像生成は、通常の作業の3〜5倍の速さで使用量を消費します。 まず代表3枚で試してから全部を作る、という進め方をAIが提案します。乗ってください。

入れる

Claude Code でも Codex でも使えます。 お使いの方だけを読んでください。1回やれば終わりです。

Claude Code をお使いの場合

/plugin marketplace add tamkai/slide-kit
/plugin install slide-kit@slide-kit

画像スライド（A）も使うなら、続けてこれも。B しか使わないなら飛ばして構いません。 

/plugin marketplace add openai/codex-plugin-cc
/plugin install codex@openai-codex

Codex をお使いの場合

codex plugin marketplace add tamkai/slide-kit --ref main
codex plugin add slide-kit@slide-kit

画像生成は Codex に組み込みなので、追加のプラグインは要りません。

準備する（共通）

/slide-setup

必要なものを調べて、足りなければ自動で入れます。フォントも自動で入ります（管理者権限は不要）。 数分かかることがあります。終わると、AとBのどちらが使えるか教えてくれます。

Codex をお使いの方へ

Codex は安全のため、既定でインターネット接続を止めています。 準備中に接続の許可を聞かれたら、許可してください（フォントのダウンロードに使います）。 許可できない場合は、手動での入れ方が案内されます。

使う

覚えるのは、この2つだけです。

この原稿からスライド構成を作って   # ← 構成が出る。ここで直す
これをスライドにして              # ← A/B を聞かれる

原稿はファイルを渡しても、その場に貼り付けても構いません。 「誰に向けた、何のための資料か」を一緒に伝えると、構成の精度が上がります。

原稿がなくても始められます

むしろ、ここがいちばん誤解されるところです。

原稿は、整った文章でなくて構いません。 箇条書きでも、思いついた順のメモでも十分です。 きれいな文章を書こうとすると、そこで手が止まります。

何もない状態で頼めば、いくつか質問されます。 答えるだけで原稿ができます。

いい資料になるかどうかを分けるのは、文章のうまさではありません。 次の3つが入っているかどうかです。

入れるものなぜ要るか
誰が、聞き終わって何をできるようになるか ここから逆算して構成が決まります。「〜を理解する」ではなく「〜できるようになる」で書くと強くなります
聞き手がどこで「え？」となるか これが枚数配分を決めます。ここが分からないと、全部が均等割りの退屈な資料になります
具体例・失敗談・数字 差がつくのはここだけです。一般論はAIが埋められますが、あなたの経験は埋められません
いちばん速いやり方

書こうとせず、誰かに説明するつもりで5分喋って、その文字起こしを渡すのが、 実は最速で、いちばん中身が濃くなります。音声入力が使えるなら試してみてください。

見た目を変えたいとき

画像スライド（A）の世界観は、差し替えられます。 スライドスタイルのギャラリー に160種類のデザインが公開されているので、好きなものを選んで 「YAMLをコピー」し、そのまま Claude Code に貼って 「このスタイルで作って」と言えば通ります。

ギャラリーは KUMIKO SHIRAKI 氏の制作物です。ライセンス表記が見当たらないため、 商用案件で使う場合は事前に確認するのが安全です。

困ったとき

/slide-setup

まずこれを打ってください。環境を調べ直して、直せるものは自動で直します。 これで解決しないときは、画面に出ているエラーをそのまま貼り付けて 「これどういう意味？」と聞けば、たいてい進めます。

よくあること
  • PowerPointで文字が明朝体になっている — フォントが入っていません。/slide-setup を実行してから、PowerPointを開き直してください。
  • 作ったPPTXを人に送ったら見た目が崩れた — 相手にフォントがないためです。PowerPointの「ファイルにフォントを埋め込む」を有効にして保存し直すと崩れません。
  • 画像スライドが作れないと言われた — Codex の画像生成が使えない環境です。Windowsで起きやすい既知の不具合です。編集できるスライド（B）は使えます。
  • 構成が気に入らない — スライドにする前に、遠慮なく何度でも直してください。ここで直すのが一番安上がりです。
