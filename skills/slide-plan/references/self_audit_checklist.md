# 自己監査チェックリスト

slide-plan の設計哲学 の Phase 2 で使用。生成スキルへ引き渡す前に**全項目クリア**を確認する。

不合格項目があれば DECK_PLAN.md に戻る。「合格してから生成に入る」を絶対ルールとする。

---

## Phase 2A: モード整合チェック

- [ ] DECK_PLAN.md の先頭に `mode` と `visual_first_ratio` が宣言されている
- [ ] 宣言したモードと、実際の Tension Map / Accent Placement が整合している
- [ ] モードが途中で切り替わっていない（前半 document / 後半 workshop のような混在なし）
- [ ] projection / workshop モードなら speaker_notes が全スライドに準備されている

---

## Phase 2B: 希少性の三原則

### 原則 1: 色の希少性

- [ ] 全スライドで、アクセント色（赤等）の画面占有が **5% 未満**
- [ ] 大面積ベタ塗りのアクセント色なし（フルブリード赤、カード全体赤、等）
- [ ] 1 スライドあたりアクセント色の使用箇所は 1-3 箇所まで
- [ ] 同一スライド内で複数のアクセント色を併用していない（赤と青が両方登場等）

### 原則 2: レイアウトの希少性

- [ ] visual-first ratio が宣言した値の ±5% 以内
- [ ] visual-first スライドが 5 ポジション（または workshop mode での均等配置）に配置されている
- [ ] visual-first の連続配置（3 枚以上連続）がない
- [ ] visual-first 冒頭集中（最初の 5 枚全部 visual-first）がない

### 原則 3: 記号の希少性

- [ ] デッキ全体のピクトグラム使用率が **20-30% 以下**（使用スライド数 / 全スライド数）
- [ ] 1 ページあたりピクトグラム **最大 2 個**まで
- [ ] 箇条書きの全行にアイコン配置がない
- [ ] カード全枚に同サイズアイコンの等間隔配置がない
- [ ] 全てのアイコンについて「なぜここに必要か」を 1 文で説明できる

---

## Phase 2C: Tension Map ルール

### 5 つの自己監査ルール

- [ ] **Rule 1**: 連続する 3 スライドで同じ tension スコアを使っていない
- [ ] **Rule 2**: 連続する 3 スライドで同じレイアウト / パターンを使っていない
- [ ] **Rule 3**: text-hero（極大文字スライド）の使用が **1 デッキで最大 3 回以下**
  - 実際の使用回数: _____ / 3
- [ ] **Rule 4**: tension 10 の使用が **1 デッキで 1-2 回以下**
  - 実際の使用回数: _____ / 2
- [ ] **Rule 5**: 連続 2 スライドの tension 差が **5 以上のジャンプを 1 箇所以上**
  - 該当箇所: S____ → S____ = +_____

### 山谷の設計

- [ ] クライマックス（tension 10）がデッキの 40-60% 地点に配置されている
- [ ] 凪（tension 4-5 の連続）があり、読者が休める区間がある
- [ ] 最終スライドが tension 10 ではない（余韻のためクールダウンあり）
- [ ] カバーが tension 3-5（静かな導入）

---

## Phase 2D: Accent Placement ルール

Document mode の場合のみ適用。Workshop mode は Phase 2E へ。

### 5 ポジション充足チェック

- [ ] **① Cover**: visual-first で第一印象が作られている
- [ ] **② 章扉**: 各章に visual-first の扉がある（または小型デッキなら Ch 数に応じて調整）
- [ ] **③ Climax**: 最重要メッセージ 1 枚が中盤に text-hero で配置されている
- [ ] **④ 顧客の声/ケース**: 証拠となる quote 風スライドがある（必要な場合）
- [ ] **⑤ CTA**: 最終本編で行動喚起の visual-first がある

### 比率と配置の品質

- [ ] 全体の visual-first ratio が 15-33% 以内（document）/ 25-33% 以内（projection 寄り）
- [ ] visual-first が**連続配置**されていない（間に text スライドを挟む）
- [ ] visual-first の色使いが派手すぎない（accent 色 1 箇所のみ）
- [ ] visual-first に文字を詰め込んでいない（1 フレーズ原則）

---

## Phase 2E: Workshop Mode 追加チェック

Workshop / Pure Projection モードの場合のみ。

- [ ] visual-first ratio が 70% 以上
- [ ] text-heavy スライドが accent として少数配置されている
- [ ] **speaker_notes が全スライドにある**（必須）
- [ ] クライマックススライドの speaker_note に「一呼吸置く」指示がある
- [ ] 1 スライドあたりの文字量がキーワード級（長文解説なし）

---

## Phase 2F: テーマ固有の禁則

使用テーマ（themes/{name}/theme.md）の禁則リストを **全て遵守** しているか。

例：

- [ ] アクセント色（赤）の画面面積が 5% を超えない
- [ ] `.text-hero` と `.text-2xl` を同じスライドに同時使用しない
- [ ] 写真を矩形にきっちり収めない（fullbleed, シェイプマスク, はみ出しのいずれか）
- [ ] Tailwind 既定カラー（`bg-red-500` 等）を使っていない
- [ ] font-family を直書きしていない

**他のテーマの場合は、そのテーマの禁則リストを個別に確認すること**。

---

## Phase 2G: 写真素材の準備状況

- [ ] 必要な写真素材がリストアップされている（写真素材プラン）
- [ ] 各素材の入手経路が明示されている（クライアント提供 / ストック / 要撮影）
- [ ] `data-hint` が抽象的（「写真」「イメージ」）ではなく具体的
- [ ] photo-placeholder を「小さく地味に」置いていない（後から差し替えやすいよう目立つ形）

---

## Phase 2H: Speaker Notes 品質

`mode = projection / workshop` の場合のみ。

- [ ] 全スライドに speaker_note が書かれている
- [ ] 各 speaker_note が 2-4 行で簡潔
- [ ] **複数発表者**がいる場合、中立的記述になっている
- [ ] 重要なスライドには具体的な演出指示（「一呼吸置く」「動画 URL を共有」等）
- [ ] 時間配分や目安が必要なら記載

---

## 判定

### 全項目クリア

→ 生成スキルへ引き渡して OK。実装フェーズへ進む。

### 不合格項目あり

→ DECK_PLAN.md に戻り、該当箇所を修正。再度チェックリスト全体を実行。

**絶対ルール**: チェックリストが全項目クリアしない限り、生成スキルに引き渡さない。実装途中で気づいた場合は、いったん中断して DECK_PLAN に戻る。

---

## チェックリストの運用

- DECK_PLAN.md と同じディレクトリにコピーして運用する
- 各項目にチェックを入れながら自己監査する
- 不合格項目の修正履歴を記録（「S06 の tension が 9 だったので 10 に修正」等）
- 完了日時を記録（最終チェック: YYYY-MM-DD HH:MM）
- このファイル自体は skill のテンプレート、各プロジェクトではコピーして使う
