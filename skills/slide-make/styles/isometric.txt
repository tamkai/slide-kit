## Visual Style: Isometric Slide — warm parchment / sage / gold, seminar-grade

This is a SLIDE for a live seminar (projected on a screen), not a dense infographic.
It must read instantly from across a room: one big idea, generous whitespace, a few short labels.

### Core Style
- Isometric (axonometric) projection, organized diorama feel
- Matte clay-like / soft-plastic 3D rendering for every object (same finish across all slides)
- Calm, editorial, premium Japanese business-magazine quality — NOT cartoonish, NOT playful, NOT cluttered
- Slightly retro-futuristic, structured, sophisticated

### CRITICAL: Cross-slide consistency (every slide in this deck MUST match)
- EXACT SAME rendering style, line weight, color saturation, and matte clay finish on every slide
- Same background tone, same lighting direction (top-left soft light), same object scale relative to canvas

- Consistent isometric camera angle across all slides

- Primary structures: Sage green #8B9A7D and #5E6E52

- Accent objects (use sparingly): Dusty rose #E8A598, #F0C4BB
- Outlines & text: Deep forest #2C3330
- Light fills: Sage mist #F4F6F2, #E2E8DD

- Speech bubbles, microphone (for voice input), gear, lightbulb, document/book, key (for API key), padlock
- Small simplified human clay figures interacting with the objects

### TEXT RULE (GPT-Image2 renders Japanese reasonably well — follow the per-slide design)
- Render the Japanese keywords / short labels specified in each slide's design brief. Prefer short keywords (2–8 chars) on clean GOLD (#C4A057) banner/tag elements with dark (#2C3330) text, placed beside the relevant object.

- Let the isometric objects carry most of the meaning; text anchors key concepts, it does not replace the illustration.

### Layout for a slide
- ONE clear focal concept, centered or with a left-to-right flow
- Strong whitespace; do NOT fill the whole frame; no thumbnail-grid / contact-sheet look
- Leave breathing room at top or one side for the (separately added) title
- Readable hierarchy: main object largest, supporting objects smaller around it

### Tone
- Restrained, refined, grounded. The illustration supports the idea; it never overpowers it.
