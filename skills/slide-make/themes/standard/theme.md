# standard theme

Slide Kit の **既定テーマ**。特定のブランドに寄らない、中立で端正な見た目。
社内説明・提案・セミナー資料など、用途を選ばず使える。

**迷ったらこれを使う。**

## Voice / Personality

- **端正で、主張しない** — 資料の主役は内容。テーマは黒子に徹する
- **静かなコントラスト** — 真っ黒(#000)を使わず濃紺グレー(`--brand-ink`)を主役に。投影時に硬くなりすぎない
- **アクセントは1色だけ** — 青(`--brand-accent`)のみ。色数で情報を整理しようとしない
- **余白を守る** — 詰めない。1スライド1メッセージを支えるのは余白

## Color palette

| トークン | 値 | 役割 |
|---|---|---|
| `--brand-paper` | `#FFFFFF` | 地の色 |
| `--brand-subtle` | `#F4F5F7` | 薄い面。カード・帯 |
| `--brand-muted` | `#E3E6EA` | 罫線・境界 |
| `--brand-ink` | `#1F2733` | 主役テキスト |
| `--ink-soft` | `#4A5462` | 補助テキスト |
| `--ink-faint` | `#8A94A2` | 控えめテキスト・注記 |
| `--brand-accent` | `#2D6BD4` | **唯一のアクセント** |
| `--accent-deep` | `#1E4FA3` | アクセントの濃い版 |
| `--accent-tint` | `#E8F0FC` | アクセントの薄い面 |

**意図**: 白地に濃紺グレー。アクセントは青1色に限定する。
色を足したくなったら、まず「足さずに済ませられないか」を疑うこと（希少性の三原則）。

## Typography

**Gen Interface JP**（SIL OFL 1.1）を使う。slide-setup が自動導入する。

| 役割 | フォント | ウェイト |
|---|---|---|
| 見出し | `Gen Interface JP Display` | 600 / 700 |
| 本文・UI | `Gen Interface JP` | 400 / 500 / 700 |

| クラス | サイズ | 用途 |
|---|---|---|
| `.hero` | 64px | 表紙・章扉の主役 |
| `.title` | 40px | 各スライドのタイトル |
| `.lead` | 28px | 結論ひとこと・リード文 |
| `.body` | 20px | 本文 |
| `.caption` | 15px | 注記・出典 |

**ジャンプ率を上げすぎない。** 見出しと本文の差を極端にすると、
読み物として落ち着かなくなる。

## 使い分け

| 背景クラス | 使う場面 |
|---|---|
| `.bg-paper` | 通常のスライド。**これが大半** |
| `.bg-subtle` | 補足・並列の面を作りたいとき |
| `.bg-cover` | 表紙・章扉のみ |
| `.bg-ink` / `.bg-accent` | クライマックス1枚だけ。連発しない |

## 禁則

- **アクセント色を2色目・3色目に増やさない**。青1色で足りないなら、色ではなく構造で解く
- **`.bg-accent` を通常スライドに使わない**。効かせどころは1デッキに1〜2枚
- **強調は `<b>` / `<strong>` / `.accent` の3つだけ**を使う。
  これ以外で強調すると、**抽出型PPTX変換で run として拾われず、太字・アクセント色が消える**
- **色を hex で直書きしない**。必ずCSS変数を経由する
- 真っ黒(`#000`)・純色の赤や黄を使わない

## PPTX変換時の注意

CSSの `font-weight` は、PPTXでは**ウェイトごとに別のフォント名**に変換される
（`font-weight: 500` → `Gen Interface JP Medium`）。
自分で変換スクリプトを書く場合は `scripts/fonts.js` の `resolveFont()` を必ず通すこと。

理由と対応表 → `../../references/fonts.md`
