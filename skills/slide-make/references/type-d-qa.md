# タイプD — 検品

生成画像を開いて確かめる。プロンプトや生成ログでは判定しない。
**構造か文字が不合格なら、絵が美しくても不合格。**

## 1. 構造（`diagram.contract` と照合）

- [ ] 要素の数が合っている（数えた）
- [ ] 矢印の本数と向きが合っている（指でたどった）
- [ ] 循環図は最後の工程が最初に戻っている。中央のラベルが工程に見えない
- [ ] ベン図は集合の数が合っている。真の重なりがある
- [ ] 枝や層が勝手に増えていない。枝同士がつながっていない
- [ ] 大きさや順序に、指定していない意味が生まれていない（ピラミッドが権力図に見える、など）
- [ ] 文字を隠しても、重なり、順序、循環、広がり、積層のどれかが読める

## 2. 文字（`type_d/text_checklist.md` と照合）

- [ ] 指定した文字列を**1つずつ**照合した。眺めて「読める」で済ませない
- [ ] 抜けがない（2026-11-06 の実例: 番号「1.〜4.」が丸ごと抜けた）
- [ ] 誤字がない（実例: マインドマップ → ベインドマップ、個人 → 創人）
- [ ] 指定していない文字が足されていない（看板、ロゴ、ページ番号）
- [ ] 発表の画面で読める大きさがある

小さい文字ほど誤りやすい。必要な枚は拡大して確かめる:

```bash
magick images/slide_05.png -crop 1280x400+0+900 +repage /tmp/check.png
```

## 3. 主役

- [ ] 図が主役で、人物や題材に押しのけられていない
- [ ] 人物を消しても図が成り立つ
- [ ] 指定していないキャストや小道具が出ていない
- [ ] 同じカード配置の繰り返しになっていない

## 4. 画風と揃い

- [ ] 色だけでなく、線、形、質感が画風どおり
- [ ] 図の部品も同じ世界で描かれている（人物だけ画風どおりになっていない）
- [ ] デッキ全体で地、質感、文字が揃っている
- [ ] 隣のスライドの内容や構図が混ざっていない

## 5. 技術

- [ ] 全枚 2560x1440 で、取り違えの警告が出ていない
- [ ] 端で図や文字が切れていない。余白が詰まりすぎていない
- [ ] PPTX を PDF にして全ページを見た

## 判定と記録

| 結果 | 対応 |
|---|---|
| 文字の小さな誤り | 部分修正 |
| 部分修正で2回直らない | 作り直す |
| 構造の間違い | 作り直す |
| 図が主役でない | `visual_brief` か画風パックを直してから作り直す |

検品表に、合格、不合格、**未確認**を分けて残す。見ていない項目を合格にしない。
同じ問題が繰り返されたら、理由とともに画風パックの `pack.json`（`fit.note`）か、この手順書に戻す。
